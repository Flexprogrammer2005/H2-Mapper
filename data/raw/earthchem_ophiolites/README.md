# EarthChem global ophiolite workbook

- File: `1307-1_Ophiolite_ALL.xlsx`
- Source: PetDB Team (2019), *EarthChem Data-To-Go: Geochemical Data for
  Ophiolites, version February 2019*, DOI: 10.1594/IEDA/111307
- Landing page: https://ecl.earthchem.org/view.php?id=1307
- Licence: CC BY-SA 4.0
- Retrieval date: 2026-10-18

The original workbook is retained unchanged. The derived GeoJSON contains
unique coordinate locations from its `Data` worksheet and preserves source
identifiers, rock-name classes, and references. It must not be interpreted as
an ophiolite-boundary map or a hydrogen-occurrence dataset.
